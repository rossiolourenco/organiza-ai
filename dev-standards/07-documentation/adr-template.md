# Template — Architecture Decision Record (ADR)

> Salvar cada ADR como `docs/adr/NNNN-titulo-curto.md` no projeto real, numerado sequencialmente. Um ADR por
> decisão arquitetural relevante (ver `AI-GUIDELINES.md` princípio 5 e `05-architecture/architecture-guidelines.md`
> seção 4).

```markdown
# ADR NNNN: Título curto da decisão

- **Status:** Proposto | Aceito | Substituído por ADR-XXXX | Depreciado
- **Data:** AAAA-MM-DD
- **Decisores:** 

## Contexto

Qual problema estamos resolvendo? Que forças/restrições estão em jogo (técnicas, de prazo, de equipe)?

## Decisão

O que foi decidido, de forma direta e objetiva.

## Alternativas consideradas

| Alternativa | Prós | Contras | Motivo do descarte |
|---|---|---|---|
| | | | |

## Consequências

- Positivas: 
- Negativas / débito técnico assumido: 
- O que fica mais difícil de mudar depois desta decisão?

## Referências

- (links, discussões, benchmarks que embasaram a decisão)
```
