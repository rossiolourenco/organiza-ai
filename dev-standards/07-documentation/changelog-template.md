# Template — CHANGELOG.md

> Seguir o formato [Keep a Changelog](https://keepachangelog.com/) combinado com
> [Semantic Versioning](../08-versioning/semantic-versioning.md). Atualizado a cada release, não a cada commit.

```markdown
# Changelog

Todas as mudanças relevantes deste projeto são documentadas aqui.
O formato segue [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/),
e este projeto adere a [Semantic Versioning](https://semver.org/lang/pt-BR/).

## [Não lançado]

### Adicionado
- 

### Alterado
- 

### Corrigido
- 

### Removido
- 

## [1.1.0] - AAAA-MM-DD

### Adicionado
- Endpoint `POST /orders` para criação de pedidos.

### Corrigido
- Corrigido cálculo de frete para pedidos com múltiplos itens (#123).

## [1.0.0] - AAAA-MM-DD

### Adicionado
- Versão inicial do sistema.
```

## Categorias padrão

- **Adicionado**: funcionalidade nova.
- **Alterado**: mudança de comportamento existente.
- **Depreciado**: funcionalidade que será removida em versão futura.
- **Removido**: funcionalidade removida.
- **Corrigido**: correção de bug.
- **Segurança**: correção relacionada a vulnerabilidade (sempre destacado, mesmo que breve).
