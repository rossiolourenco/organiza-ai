# Organiza Aí

Aplicativo móvel desenvolvido para a disciplina de Desenvolvimento Mobile.

## Sobre o projeto

O **Organiza Aí** é um aplicativo para organização de tarefas pessoais e acadêmicas.

O objetivo é oferecer uma interface simples e intuitiva para que o usuário possa cadastrar, visualizar, concluir e excluir suas tarefas.

## Funcionalidades planejadas

- Tela inicial com menu principal
- Cadastro de novas tarefas
- Visualização das tarefas cadastradas
- Marcação de tarefas como concluídas
- Exclusão de tarefas
- Visualização das tarefas concluídas

## Tecnologias utilizadas

- React Native
- JavaScript
- Expo
- Expo Go
- Git e GitHub

## Plataforma

O aplicativo está sendo desenvolvido e testado inicialmente para **iOS**.
