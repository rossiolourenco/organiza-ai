# Cronograma de Desenvolvimento - Organiza Aí

## Projeto

**Organiza Aí** - Aplicativo móvel para organização de tarefas pessoais e acadêmicas.

## Objetivo

Desenvolver um aplicativo móvel simples para auxiliar o usuário na organização de suas tarefas, permitindo cadastrar, visualizar, concluir e excluir tarefas.
